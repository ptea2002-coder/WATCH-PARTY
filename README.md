# WATCH//PARTY

Giao diện prototype dark mode cho trải nghiệm xem phim cùng bạn bè.

## Chạy local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Trạng thái hiện tại

Đây là frontend prototype dùng React + Vite. Danh sách phòng, thành viên và chat đang dùng dữ liệu mẫu/local state trong trình duyệt. Chưa kết nối backend, cơ sở dữ liệu, realtime hoặc đồng bộ video.
